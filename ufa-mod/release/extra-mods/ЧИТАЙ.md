# Дополнительные моды

Копии четырёх модов, с которыми мод «Уфа: День экзамена» проверен. Скопируй все `.jar` из этой папки
в папку `mods` рядом с `ufamod-1.4.0.jar`. Мод работает и без них.

Файлы не изменены: это оригиналы с Modrinth (контрольные суммы SHA-1 ниже совпадают с опубликованными).
